# Security Policy

Do not report vulnerabilities through public issues, commits, or pull requests. Do not include secrets, recordings, transcripts, customer information, or reproduction data containing personal data.

Report security concerns privately to the repository owner with a description, affected component, impact, and safe reproduction steps. The owner will acknowledge receipt, assess the issue, and coordinate remediation.

The Apache-2.0 license does not authorize security testing against production systems, provider accounts, customer data, or phone numbers.
